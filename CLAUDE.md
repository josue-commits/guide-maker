# Maintaining this repo

`AGENTS.md` is a symlink to this file. Every invariant below is something a change has to keep; CI checks the ones it can.

1. **Every `skills/*/SKILL.md` is listed** in `README.md` Reference and in `skills/README.md`, name linked to the `SKILL.md`, grouped Pipeline / Assets and User-invoked / Model-invoked. Six skills today: `setup-guide-maker`, `ask-guide-maker`, `make-guide`, `topic-finder`, `graphics-maker`, `dm-automation`.
2. **Every skill has a page** at `docs/skills/<name>.md`, written to [.agents/writing-docs.md](.agents/writing-docs.md). Add, rename or change a skill's behaviour and the page moves with it; a rename deletes the old page.
3. **`ask-guide-maker` is re-synced** whenever a skill, an on-ramp, or a row of the pipeline table in `skills/make-guide/SKILL.md` changes. A router that names a skill that is gone, or misses one that exists, is a router that lies.
4. **Every `SKILL.md` is user-invoked or model-invoked** per [.agents/invocation.md](.agents/invocation.md). User-invoked (`setup-guide-maker`, `ask-guide-maker`) carry `disable-model-invocation: true` and a human-facing description. Dependencies on model-invoked skills are Skill tool calls; the precondition on the user-invoked setup is "tell the user to run `/setup-guide-maker`". Hard dependency in `make-guide` and `dm-automation`, soft in `graphics-maker` and `topic-finder`.
5. **Nothing under `skills/` is written at run time.** Config, overrides, format cards and logs live in the project's `.guide-maker/` (or `~/.config/guide-maker/`). A script that opens a file for writing under `skill_dir()` is a bug. The smoke test asserts `git status --porcelain skills/` is empty after a full run.
6. **`_config.py`'s public surface is a contract** ([.agents/config-contract.md](.agents/config-contract.md)) imported by `graphics-maker/scripts/_cfg.py`, `dm-automation/scripts/_config_shim.py` and the doctor. Change the surface in all of them in one commit, and run `bash tests/run_smoke.sh` before it lands.
7. **Every `DEFAULTS` key is documented** in `skills/make-guide/config.example.yaml`, with a comment. Every script that writes takes `--config` and `--dry-run`; every script has `--help` and exits non-zero on failure.
8. **`skills/topic-finder` is a git subtree.** Edit upstream, then `git subtree pull --prefix skills/topic-finder https://github.com/josue-commits/topic-finder.git <tag> --squash`. Never edit it here ([ADR 0003](.agents/adr/0003-topic-finder-vendored-as-a-subtree.md)).
9. **Install wording comes only from [.agents/install-block.md](.agents/install-block.md).** `README.md` carries the block between `<!-- install-block:start -->` and `<!-- install-block:end -->`; `docs.yml` diffs the two. Pages under `docs/` carry no install commands.
10. **`VERSION` matches the top `## x.y.z` heading in `CHANGELOG.md`**, and the tag `vx.y.z` matches both. `scripts/check_version.py --check` runs in CI and on release ([.agents/release.md](.agents/release.md)).
11. **No em dashes, no private strings.** No U+2014 or U+2013 anywhere; rewrite the sentence. No author name outside README Background, no organisation names, no tokens, no 32-hex Notion ids outside the `0123456789abcdef...` fixture. CI greps for all of it.
12. **Dev loop.** From a checkout, `npx skills add . --agent claude-code` links the six skills into the harness; re-run after adding, removing or renaming a skill. `bash tests/run_smoke.sh` is green at every commit that touches a script or a test.

Decisions with a "why" live in [.agents/adr/](.agents/adr/). Things the repo will not do live in [.out-of-scope/](.out-of-scope/). The distribution decision (skills.sh and `install.sh`, no plugin) is [ADR 0002](.agents/adr/0002-distribute-through-skills-sh-and-install-sh-no-plugin.md).
