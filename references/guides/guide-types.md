# Guide Type Classification

Read the full source material, then classify into one of three types.

## Technical Tutorial
**Signals:** Installation steps, code snippets, terminal commands, API integrations, config files, "first do this, then do that" patterns.
**Examples:** `references/notion-guides/01-ai-sales-team-guide.md`, `references/notion-guides/03-clawdbot-guide.md`

## Strategic Framework
**Signals:** Methodology, phases, timelines, growth tactics, high-level approach, mental models.
**Example:** `references/notion-guides/02-linkedin-growth-blueprint.md`

## Comparison/Persuasion
**Signals:** Comparing tools/approaches, cost analysis, before/after, ROI discussions, "why X beats Y."
**Example:** `references/notion-guides/04-ghostwriter-comparison.md`

## Detection Process
1. Read the full source before classifying
2. If mixed, default to the type that covers 60%+ of the content
3. Present to user: "This looks like a **[Type Name]**. Here's my planned outline:" and wait for confirmation
